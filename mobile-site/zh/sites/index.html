列表中没有匹配的网站。在 Forumind 中打开任何 Discourse 论坛或 WordPress 网站，App 会告诉你能不能用。

Discourse 论坛

任何自定义域名的 Discourse 论坛，公开的或需要登录的。在 App 里登录，它就能读你能读的内容。

WordPress 网站

通过网站公开的 REST API 读取文章和评论（/wp-json/wp/v2/）。关闭了该接口的网站不受支持。

Hacker News

通过 Algolia 的公开 HN API 读取文章和评论。只读：不能登录、发帖或投票。

不确定某个网站能不能用？在 Forumind 里打开它，App 会告诉你。以上网站仅作举例，Forumind 与它们无任何关联。

首页 支持的网站 隐私政策 帮助支持

Forumind 是一款独立 App，与 Discourse、WordPress、Hacker News 及其所有者没有任何关联，也未获其认可。

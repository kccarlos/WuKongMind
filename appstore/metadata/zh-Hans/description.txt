WukongMind 浏览器是一款面向 iPhone 和 iPad 的网页浏览器，内置可在任意网页上阅读、修改并执行自动化任务的 AI 智能体。

浏览任意网站
使用标签页、标签页概览、地址栏、历史记录和置顶网站自由浏览开放网络。专为 iPhone 和 iPad 打造，在 iPad 上网页与助理可并排显示。

让智能体修改任意网页
在任意网页打开助理，直接说出你的需求：“把这个网页改成深色”“隐藏侧边栏”“把字体调大”或“把表格整理成清晰列表”。智能体编写 JavaScript 和 CSS，在当前网页的 WebKit 环境中运行，并清晰展示每一步操作。运行期间“停止”按钮始终可见。

将修改保存为你批准的脚本
喜欢智能体做出的调整？让它保留更改，以便下次访问自动生效。保存或更新任何脚本前，WukongMind 都会展示完整源代码、匹配网站与所请求的权限，经你批准后才会写入。你可随时在“设置 › 脚本”中查看、开关或删除每个脚本。

用户脚本
通过任意 HTTPS 链接导入标准 .user.js 用户脚本。添加或启用前，WukongMind 会完整呈现源代码和权限说明。可选的每日更新检查只会在有新版本时提醒你，绝不会未经审核自动替换。

随问随学
当你针对某个网站提问时，智能体可以在你的批准下为该网站学习一个轻量只读阅读器，并在后续复用它以更快地搜索网站并回答问题。

摘要与朗读
为任意长文章或讨论生成摘要、继续追问、跨站点搜索，并使用设备语音或你自己的语音服务朗读内容。

与网页实时对话
使用你自己的 API 密钥开启实时语音，直接开口询问当前网页。发送麦克风音频前会单独征求你的同意，离开 App 时语音会话自动结束。

翻译与关注讨论
在设备端翻译屏幕上的文本或摘要（需要 iOS 18 或更高版本）。选择关注讨论页面，有新回复时接收通知。

SIRI、快捷指令与聚焦搜索
使用 Siri 和快捷指令摘要链接、向网站提问或开启语音会话。你读过的页面可选择性地出现在聚焦搜索中。

AI 由你选择（自带密钥）
使用你自己的 API 密钥连接主流云端 AI 提供方，或连接局域网内的本地模型服务器。在受支持的设备上，Apple 智能无需密钥即可用于网页摘要。首次向第三方 AI 服务发送数据前，WukongMind 会说明发送内容并征求你的明确同意；你可随时在设置中撤回同意，或举报任意 AI 回答。

默认安全与隐私
- “写入前确认”默认开启，Cookie 值默认不对模型可见，脚本保存与修改默认需经你批准。
- 没有 WukongMind 账号，没有广告，没有分析，没有跟踪，也没有 WukongMind 服务器。
- API 密钥安全保存在钥匙串中，可选的 iCloud 同步仅使用你自己的私人 iCloud 账号。
- 可选广告与跟踪器拦截（EasyList 与 EasyPrivacy，CC BY-SA 3.0）默认关闭，并内置温和的网站请求节奏。

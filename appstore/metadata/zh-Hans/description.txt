Forumind 帮你跟上冗长的论坛讨论。它是一款论坛浏览器，旁边配有 AI 助手：总结长篇话题、继续追问，还能让助手替你搜索整个论坛，并附上它引用的帖子链接。支持任何 Discourse 论坛、WordPress 网站和 Hacker News。

不必再逐帖翻阅
无需读完每一楼，就能掌握 500 条回复的话题要点：原帖内容、大家怎么说，以及帖子里的实用建议，并附上可轻点的楼层编号。之后轻点“检查新回复”，只会读取新的帖子。

随时提问
就你正在阅读的话题聊一聊：“大家最后怎么决定的？”“有没有变通办法？”编辑问题即可重新提问，还能为单个话题设置专属指令。

问论坛
提出一个问题，助手会搜索论坛、阅读最相关的话题，并给出附带编号来源的回答，轻点即可核对。

DISCOURSE、WORDPRESS 与 HACKER NEWS
打开任何 Discourse 论坛，App 会自动识别；如果论坛需要登录，直接在 App 内登录即可，你的登录信息只会发送给该论坛。WordPress 网站通过其公开的 REST API 使用：阅读文章及读者评论。对于 Hacker News，助手通过公开的 Algolia API 读取故事和评论，App 内浏览器则显示网站本身。可置顶你最常用的网站。

今日：摘要与播客
“今日”页面汇集你关注的话题中的新回复，以及置顶论坛的热门话题。你可以把它变成一段简短的双主持人播客，由设备自带的语音朗读，或使用你自己的 Google 密钥，由 Google 的语音朗读。任何摘要也都可以朗读出来。

和页面对话
实时语音让你直接开口询问正在阅读的页面，使用 Google Gemini Live 和你自己的密钥。使用前会先征得你的同意，因为你的语音和页面内容会发送给 Google。

翻译
在设备上翻译屏幕上的帖子或摘要（需要 iOS 18 或更高版本）。

分享、SIRI 与聚焦搜索
把 Safari 或 Chrome 中的任何论坛页面分享给 Forumind，并选择要做什么；打开 Forumind，它就在那里等着你。用 Siri 和快捷指令来总结链接、问论坛、打开今日摘要、播放播客或开始语音对话。你读过的话题可以显示在聚焦搜索中（可选）。

关注话题
你关心的话题有新回复时，会收到通知。

安全浏览
举报帖子或话题，屏蔽用户，让对方的帖子在 App 中处处消失，并隐藏包含你所选词语的帖子。

AI 由你选择
在支持的设备上使用 Apple 智能：无需账户，也无需密钥。或者用 API 密钥接入你自己的 AI 提供方，包括许多热门云服务，也可以在你自己的电脑上运行模型。任何内容首次发送给提供方之前，App 都会告诉你将发送什么并征求你的同意。

善待论坛
Forumind 默认每秒只读取话题的一页，绝不会让论坛服务器不堪重负；你可以在“设置”中调整速度。广告和跟踪器拦截（EasyList 与 EasyPrivacy）为可选功能，默认关闭，以尊重依靠广告维持运营的论坛站长。

覆盖你的所有设备
专为 iPhone 和 iPad 打造，在 iPad 上论坛与助手并排显示。你的论坛、摘要、聊天和设置通过你自己的 iCloud 账户同步，并经过端到端加密。

设计即隐私
- 没有账户，没有分析，没有广告，没有跟踪。
- 没有 Forumind 服务器。App 直接与你打开的网站和你选择的 AI 通信，并且每天从 GitHub 下载一次我们公开的审核列表。
- API 密钥存储在你的钥匙串中。
- 你的历史记录只保存在你的设备和你自己的 iCloud 中。

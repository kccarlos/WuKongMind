WukongMind 瀏覽器是一款專為 iPhone 與 iPad 打造的網頁瀏覽器，內建可在任何網頁上閱讀、修改並執行自動化任務的 AI 代理。

瀏覽任何網站
透過分頁、分頁概覽、網址列、瀏覽記錄與釘選網站自由瀏覽開放網路。專為 iPhone 與 iPad 設計，在 iPad 上網頁與助理可並排顯示。

讓代理修改任何網頁
在任何網頁開啟助理，直接說出你的需求：「把這個網頁改成深色」「隱藏側邊欄」「把字體放大」或「把表格整理成清晰清單」。代理會撰寫 JavaScript 與 CSS，在目前網頁的 WebKit 環境中執行，並清楚顯示每一個步驟。執行期間「停止」按鈕始終可見。

將修改儲存為你批准的腳本
喜歡代理做出的調整？讓它保留更改，以便下次造訪自動套用。儲存或更新任何腳本前，WukongMind 都會展示完整原始碼、配對網站與所請求的權限，經你批准後才會寫入。你可隨時在「設定 › 腳本」中檢視、開關或刪除每個腳本。

使用者腳本
透過任何 HTTPS 連結匯入標準 .user.js 使用者腳本。加入或啟用前，WukongMind 會完整呈現原始碼與權限說明。選用的每日更新檢查只會在有新版本時通知你，絕不會未經審核自動替換。

隨問隨學
當你針對某個網站提問時，代理可以在你的批准下為該網站學習一個輕量唯讀閱讀器，並在後續重複使用以更快搜尋網站並回答問題。

摘要與朗讀
為任何長篇文章或討論產生摘要、繼續追問、跨站搜尋，並使用裝置語音或你自己的語音服務朗讀內容。

與網頁即時對話
使用你自己的 API 金鑰開啟即時語音，直接開口詢問目前網頁。傳送麥克風音訊前會單獨徵求你的同意，離開 App 時語音工作階段會自動結束。

翻譯與追蹤討論
在裝置端翻譯螢幕上的文字或摘要（需要 iOS 18 或更新版本）。選擇追蹤討論頁面，有新回覆時接收通知。

SIRI、捷徑與聚焦搜尋
使用 Siri 與捷徑摘要連結、向網站提問或開啟語音工作階段。你讀過的頁面可選擇性地出現在聚焦搜尋中。

AI 由你選擇（自備金鑰）
使用你自己的 API 金鑰連接主流雲端 AI 供應商，或連接區域網路內的本地模型伺服器。在支援的裝置上，Apple Intelligence 無需金鑰即可用於網頁摘要。首次向第三方 AI 服務傳送資料前，WukongMind 會說明傳送內容並徵求你的明確同意；你可隨時在設定中撤回同意，或檢舉任何 AI 回答。

預設安全與隱私
- 「寫入前確認」預設開啟，Cookie 值預設不對模型可見，腳本儲存與修改預設須經你批准。
- 沒有 WukongMind 帳號，沒有廣告，沒有分析，沒有追蹤，也沒有 WukongMind 伺服器。
- API 金鑰安全儲存在鑰匙圈中，選用的 iCloud 同步僅使用你自己的私人 iCloud 帳號。
- 選用廣告與追蹤器阻擋（EasyList 與 EasyPrivacy，CC BY-SA 3.0）預設關閉，並內建溫和的網站請求節奏。

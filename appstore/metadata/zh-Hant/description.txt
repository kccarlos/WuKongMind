Forumind 幫你跟上冗長的論壇討論。它是一款論壇瀏覽器，旁邊配有 AI 助理：摘要長篇話題、繼續追問，還能讓助理替你搜尋整個論壇，並附上它引用的貼文連結。支援任何 Discourse 論壇、WordPress 網站和 Hacker News。

不必再逐則翻閱
無需讀完每一樓，就能掌握 500 則回覆的話題重點：原文內容、大家怎麼說，以及討論中的實用建議，並附上可點一下的樓層編號。之後點一下「檢查新回覆」，只會讀取新的貼文。

隨時提問
就你正在閱讀的話題聊一聊：「大家最後怎麼決定的？」「有沒有變通辦法？」編輯問題即可重新提問，還能為單一話題設定專屬指示。

問論壇
提出一個問題，助理會搜尋論壇、閱讀最相關的話題，並給出附有編號來源的回答，點一下即可核對。

DISCOURSE、WORDPRESS 與 HACKER NEWS
打開任何 Discourse 論壇，App 會自動辨識；如果論壇需要登入，直接在 App 內登入即可，你的登入資訊只會傳送給該論壇。WordPress 網站透過其公開的 REST API 使用：閱讀文章及讀者留言。對於 Hacker News，助理透過公開的 Algolia API 讀取故事和留言，App 內瀏覽器則顯示網站本身。可釘選你最常用的網站。

今日：摘要與 Podcast
「今日」頁面彙整你追蹤的話題中的新回覆，以及釘選論壇的熱門話題。你可以把它變成一段簡短的雙主持人 Podcast，由裝置內建的語音朗讀，或使用你自己的 Google 金鑰，由 Google 的語音朗讀。任何摘要也都可以朗讀出來。

與頁面對話
即時語音讓你直接開口詢問正在閱讀的頁面，使用 Google Gemini Live 和你自己的金鑰。使用前會先徵求你的同意，因為你的語音和頁面內容會傳送給 Google。

翻譯
在裝置上翻譯螢幕上的貼文或摘要（需要 iOS 18 或更新版本）。

分享、SIRI 與聚焦搜尋
把 Safari 或 Chrome 中的任何論壇頁面分享給 Forumind，並選擇要做什麼；打開 Forumind，它就在那裡等著你。用 Siri 和捷徑來摘要連結、問論壇、打開今日摘要、播放 Podcast 或開始語音對話。你讀過的話題可以顯示在聚焦搜尋中（選用）。

追蹤話題
你關心的話題有新回覆時，會收到通知。

安全瀏覽
檢舉貼文或話題，封鎖使用者，讓對方的貼文在 App 中處處消失，並隱藏包含你所選字詞的貼文。

AI 由你選擇
在支援的裝置上使用 Apple Intelligence：不需要帳號，也不需要金鑰。或者用 API 金鑰接入你自己的 AI 供應商，包括許多熱門雲端服務，也可以在你自己的電腦上執行模型。任何內容第一次傳送給供應商之前，App 都會告訴你將傳送什麼並徵求你的同意。

善待論壇
Forumind 預設每秒只讀取話題的一頁，絕不會讓論壇伺服器不堪負荷；你可以在「設定」中調整速度。廣告和追蹤器阻擋（EasyList 與 EasyPrivacy）為選用功能，預設關閉，以尊重依靠廣告維持營運的論壇站長。

涵蓋你的所有裝置
專為 iPhone 和 iPad 打造，在 iPad 上論壇與助理並排顯示。你的論壇、摘要、聊天和設定透過你自己的 iCloud 帳號同步，並經過端對端加密。

隱私至上的設計
- 沒有帳號，沒有分析，沒有廣告，沒有追蹤。
- 沒有 Forumind 伺服器。App 直接與你打開的網站和你選擇的 AI 通訊，並且每天從 GitHub 下載一次我們公開的審核清單。
- API 金鑰儲存在你的鑰匙圈中。
- 你的歷史記錄只保存在你的裝置和你自己的 iCloud 中。

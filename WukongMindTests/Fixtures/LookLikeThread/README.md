Saved pages for `LookLikeThreadProbeTests`. `forum-*` are real thread pages of four engines (FluxBB: bbs.archlinux.org, XenForo: forums.freebsd.org, Discourse: meta.discourse.org, NodeBB: community.nodebb.org) and `plain-*` real ordinary pages (Wikipedia, BBC News, Python docs, a GitHub repo), saved 2026-11-16 with scripts, styles and comments removed and cut to a size that keeps the post markup. `markup-*` are small hand-written pages for the three markup paths. Known false positive, not in the tests: a news front page such as theverge.com is flagged.

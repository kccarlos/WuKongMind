Motion shows a live signal or a cause, never decoration

The rule since 2026-11-19 (design-motion.md). Continuous motion is allowed only where it displays something happening now. The ring has one one-shot. Functional transitions stay within 250 ms with no bounce. Every state is also a still picture and a word. Haptics are not motion and stay.

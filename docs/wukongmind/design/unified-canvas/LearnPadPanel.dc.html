Which UPS for a NAS that should shut down cleanly?
31 replies · 1.2k views
[member]
My NAS draws 40 W. Which UPS lets it shut down on its own before the battery runs out?
[member]
Any unit with a USB data port. NUT on the NAS reads it; set the shutdown at 50 %.

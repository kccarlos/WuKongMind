WUKONGMIND · UNIFIED INTERFACE · REVISED FOR ROADMAP v2 "JUST ASK"

One input box on every page. Just ask.

The UI was added one milestone at a time, so it reads as a forum app with a browser bolted on. This design treats the app as a general browser with one Agent: one input box and a mic on every page, no modes, no target switch. Forum summary, search and podcast become how the Agent's tool results display. The look is the WukongMind design system: ink, gold, jade and cinnabar, and one gold ring for the Agent. In One panel the engines stay untouched.

1 · ONE INPUT BOX PLUS SUGGESTIONS
Modes become suggestions

The same panel, title "Agent" and input box on every page, with a mic. Above the box, a row of suggestions: each is a question you could type or say yourself, and a tap sends it ("Search this forum…" fills the box for you to finish). They appear only where they apply. Every result lands in one conversation the Agent remembers.

2 · CAPABILITIES FOLLOW THE PAGE
One "This page" entry

M1's "N scripts on this page" chip becomes the This page seal ("talk.example.org · 3 scripts"). Its popover holds this topic's Follow switch, the scripts on this page (M2's rows), tools on this page (Learn on ask, reserved), a developer-mode site inspector (reserved) and this site's switches (ads moved here from the title capsule).

3 · HOME IS THE START PAGE
Address, sites, recent tasks

An address field first (the only address on Home), then Today when it has something, a grid of pinned and frequent sites, Recent (the newest History items), continue reading and followed topics. Forums are ordinary tiles with a grey speech-bubble badge. Suggested forums move into Add site.

4 · SETTINGS GROUPED BY OBJECT
Each setting in one place

Assistant: Models (Agent and Summaries), Agent (with forum search limits and the developer mode switch), Scripts & tools. Sites & browsing: Sites (forums, following, pace, ads), Browser. Voice & digest: Voice, Daily digest & podcast. Your data: Sync, Data. Help & about. Browser gains a search engine picker.

5 · ONE VOCABULARY
Only the Agent is "Agent"

There are no mode names left: forum search is the suggestion "Search this forum…". Gold and the ring mean only the Agent. Script, tool, site, forum, task and History each mean one thing. Code renames are left to the cleanup's rename task.

6 · ONBOARDING IN THREE STEPS
Model, site, try it

1 Pick a model for the Agent. 2 Open a site. 3 Try the Agent on it, with two suggested prompts, and you're done. Welcome, Forums, Daily, Privacy and Done fold into these steps or move to Settings. Consent and terms go with the cleanup.

Decided with the owner (2026-11-12)

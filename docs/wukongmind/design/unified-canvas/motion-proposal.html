只有环会动：WukongMind 的动效提案

金箍的三个细环不只是 logo，它可以成为 Agent 的表情。下面每个演示都能重播；系统开启“减弱动态效果”时，它们都会退化成淡入淡出或静止。

右边是主演示：冷启动时 logo 组装，再把最外圈的环交给浏览器栏里的 Agent 按钮。它说的是一件事：这个环就是 Agent。

建议改写的规则
现在的规范：“转动的金环是唯一的持续动画，不允许装饰性动效。” 建议改成：“只有环会动，每次动都表示 Agent 的一种状态或一个结果。其余界面仍只用系统转场，≤250 ms，不回弹。” 克制的气质保留，表达力来自环。

1 · Agent 环的状态语言

今天环只有“转”一种动作。用 logo 的三环给它五种状态，用户看一眼就知道 Agent 在干什么，不用读字。

读页面每读一次放出一圈涟漪

P0思考每环 1.5 s 循环，错开 0.18 s；涟漪与 tool call 一一对应，不是装饰循环；完成缺口 300 ms 合上 + 一次 0.9× 收紧 + success 触感，随后吉祥物换成 cheer。
SwiftUI：Circle().trim(from:to:) + PhaseAnimator / keyframeAnimator；减弱动态：全部静止，只换图形。

“紧箍”本身就是很好的隐喻。站点工具验证通过、脚本保存时，一个大环从外面收紧，箍住这一项。

3 · 金线描出被改过的地方

WukongMind 的核心是 Agent 改网页。改完后用一条金色细线把变动的元素描一圈再淡出，用户立刻知道改了哪里。

广告
已改
P1在网页里注入：被删的元素 200 ms 收起，被改的元素描边 400 ms，停 1.2 s，淡出 600 ms；角上留一个“已改”印章，点开可撤销。实现在 userscript 运行层（注入 CSS + SVG/outline），不需要 SwiftUI。

4 · 语音时三环就是声纹

现在语音按钮用的是 symbol 的 pulse。换成三环随音量扩张：听你说时跟着麦克风，Agent 说话时跟着输出。

P1内环跟实时电平，外两环延迟 60/120 ms 跟随，像水波；电平做平滑避免抖动。用于 PhoneVoice 和 Sheepdog 式的免手语音。减弱动态：只用不透明度表示电平。

5 · 中缝：墨与金的切换

logo 中间那条看不见的缝，可以做深浅主题切换和引导页翻页的转场：一条金线扫过，后面变成另一半。

P2只用在用户主动切换时（设置里的外观、引导页三步），320 ms ease-in-out。日常页面跳转不用，免得变成装饰。减弱动态：交叉淡化。

指针悬停：露出三环

用触控板或鼠标指到 Agent 环上，内两环淡入，环本身轻微抬起。平时它就是一个细环，只在你准备点它时才露出 logo 的样子。

P0150 ms，配合系统 .hoverEffect(.lift) 和指针吸附。触屏上不出现。键盘焦点（Tab 到环上）显示同样的样子，⌘J 打开面板。

iPad 才有的机会

  • 面板和页面联动：并排时，指到面板里的引用编号或工具行，页面里对应的段落就用金线描出来（第 3 条的描边能力）。iPhone 抽屉挡着页面，做不到这么直接。
  • 标签页总览：四列卡片里，正在跑 Agent 的标签页在卡片角上显示小号的状态环，一眼看出哪个页面在干活。
  • 窗口变窄（Split View、台前调度）时侧栏退回成 iPhone 式抽屉，用系统转场，环的语言不变。
  • 以后：圈一下。用 Pencil 或手指在页面上画个圈，吸附成金环，把圈住的元素交给 Agent 当上下文。画圈就是金箍的动作，也呼应“画地为圈”，但西方用户不需要懂这个典故也能用。

进度指示用三个同心环代替三个点
每完成一步画上一圈，三步走完正好是 logo 的三环。之前“引导页圆点拉伸”被去掉了，这个不一样：它表示进度，不是装饰。

iPad 的第一次

  • logo 在屏幕中央组装，然后表单页从下面升起，logo 落进表单页的标题位置（第 1、2 步在 iPad 上是表单页）。
  • 第 3 步表单页关闭，网页打开时侧栏已经开着，两条建议就在侧栏里，不用抽屉。
  • 如果接了键盘，第 3 步的输入框直接获得焦点，环显示悬停时的三环样子，提示可以直接打字。

不走主线的情况

  • 第 1 步点了 Later：没有模型，第 3 步显示“还没有模型”的卡片，环保持待命不动。没有发生的事不演。
  • 以后的冷启动：不再组装，静态的纸色底直接进上次的页面，或者只做 350 ms 的交接。
  • 减弱动态：组装换成 200 ms 淡入，进度环直接出现，其余照前面的规则。

8 · 首页：像 Safari 一样，点地址栏就是首页

你截图里的首页现在有两个输入口：顶上的 “Search or enter address” 和底栏。学 Safari 之后只剩底栏一个：在任何页面点地址栏，首页就浮在当前页面上面，键盘升起，底栏贴到键盘上方。首页从“一个页面”变成“编辑地址时的状态”，新标签页也是它。

首页上的环也是活的

Recent 里 Agent 的条目本来就用金环当图标，让它和真实状态同步：还在跑的那条转着，刚跑完的那条收紧成勾，过几秒回到静止。首页一眼就能看出哪个任务还没完。

# WukongMind design files (exported for implementers)

Copies of the owner-confirmed design artifacts, so agents that can't open claude.ai artifacts can implement them. The artifacts remain the source of truth: this folder is a read-only export, never edited by hand, and is re-exported after every artifact change, with a PNG of every new or changed artboard (see [../README.md](../README.md) "Where design output lives").

- `design-system/`: the WukongMind design system (https://claude.ai/artifact/5fGhnS4fmcmWYZbPoKTTZ2), exported 2026-11-13; WUKO-107's `BrowserBar`, glass-capsule and bar-morph rules (written in the repo first) were applied to the artifact and re-exported on 2026-11-15 in task D1b (WUKO-119), design-system version 11; the motion rule, the ring's six states and the address bar's Home, edit and suggestion states ([design-motion.md](../design-motion.md)) were applied on 2026-11-20 in Motion task 8 (WUKO-200), design-system version 15 (`README.md` "The ring" and the Motion line, `components/BrowserBar` README and preview, `components/ToolRow` and `components/Composer` READMEs). `README.md` (foundations, colour meanings, the ring, shape, type, motion, the DCTheme migration table), `tokens.json` (colour tokens light/dark, type styles, spacing, radius, shadow, border), `components/<Name>/README.md` + `preview.html` (reference drawings in HTML/CSS using the token CSS variables; implement in SwiftUI), `assets/Logo/` and `assets/Mascot/` (SVGs, the 1024 app icon PNG, usage READMEs).
- `unified-canvas/`: the boards of the unified interface design (https://claude.ai/artifact/Daefr4AsZcSm2EWbTLU9uK), exported 2026-11-13 (re-exported the same day with the M3 and One loop boards, canvas version 57; WUKO-77's boards added 2026-11-14, canvas version 63, with Fable's second-review updates to `PhoneBar`, `PhoneTabs` and `PhoneProviderModels` synced back to the canvas in task D1b (WUKO-119, canvas version 66); the M4 boards added 2026-11-15, canvas version 65; the Learn on ask boards added 2026-11-15, canvas version 69 after the Fable design review; the Motion boards added and Home, onboarding, Settings and the text boards updated 2026-11-20 in Motion task 8 (WUKO-200), canvas version 74). Each `*.dc.html` is one board's markup and CSS (light theme variables in `.lt`, dark in `.dk`; `*Dark.dc.html` boards just render the light board with the dark theme). They depend on the design tool's runtime, so they won't render standalone in a browser: read them as layout and style specs. `canvas.json` lists the boards and their order. Image references point to the files in `design-system/assets/`. The written spec is `docs/wukongmind/design-unified.md`. `png/<Board>.png` holds 2x PNGs of the boards added or changed since the first export (light and dark), rendered locally with headless Chrome from these files (theme filled in, image paths pointed at `design-system/assets/`); the boards' own markup stays the spec.

# WukongMind design files (exported for implementers)

Copies of the owner-confirmed design artifacts, so agents that can't open claude.ai artifacts can implement them. The artifacts remain the source of truth: this folder is a read-only export, never edited by hand, and is re-exported after every artifact change, with a PNG of every new or changed artboard (see [../README.md](../README.md) "Where design output lives").

- `design-system/`: the WukongMind design system (https://claude.ai/artifact/5fGhnS4fmcmWYZbPoKTTZ2), exported 2026-11-13. `README.md` (foundations, colour meanings, the ring, shape, type, motion, the DCTheme migration table), `tokens.json` (colour tokens light/dark, type styles, spacing, radius, shadow, border), `components/<Name>/README.md` + `preview.html` (reference drawings in HTML/CSS using the token CSS variables; implement in SwiftUI), `assets/Logo/` and `assets/Mascot/` (SVGs, the 1024 app icon PNG, usage READMEs).
- `unified-canvas/`: the boards of the unified interface design (https://claude.ai/artifact/Daefr4AsZcSm2EWbTLU9uK), exported 2026-11-13. Each `*.dc.html` is one board's markup and CSS (light theme variables in `.lt`, dark in `.dk`; `*Dark.dc.html` boards just render the light board with the dark theme). They depend on the design tool's runtime, so they won't render standalone in a browser: read them as layout and style specs. `canvas.json` lists the boards and their order. Image references point to the files in `design-system/assets/`. The written spec is `docs/wukongmind/design-unified.md`.

Key boards: `PhonePanelForum`, `PhonePanelPage`, `PanelStates`, `KeyboardUp`, `SuggestionRow`, `PhoneThisPage` (assistant panel); `PhoneHome`, `IPadHome` (start page); `PhoneSettings`, `PhoneModels`, `PhoneAgentSettings`, `PhoneSites`, `IPadSettings` (settings); `PhoneOnb1-3`, `IPadOnb` (onboarding); `Motion`; `IA` (screen map), `Migration`, `Glossary`. `PhoneResearch` shows the One loop stage, not One panel.

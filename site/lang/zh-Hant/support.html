常見問題

需要付費嗎？

WukongMind 沒有帳號、訂閱或 App 內購買。你連接的 AI 供應商可能依用量收費。使用 Apple 智慧和你自己網路上的模型不會產生費用。

需要 API 金鑰嗎？

使用代理需要連接一個 AI：你自己的代管服務金鑰、區域網路上的模型，或在支援的裝置上使用 Apple 智慧（僅用於摘要網頁）。不用這些也可以瀏覽網頁。

哪些網站可以用？

任何網頁。代理會讀取並修改你開啟的頁面。

代理改了頁面，我想還原。

重新載入頁面即可。如果代理把修改儲存成了腳本，請在「設定 › 腳本」中關閉或刪除它。

我的資料會去哪裡？

使用代理時，只會傳送給你選擇的 AI 供應商。不需註冊，也不會收集任何資料。詳情請見隱私權政策。

有原始碼嗎？

有，在 GitHub 上。

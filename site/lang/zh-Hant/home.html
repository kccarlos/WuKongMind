它能做什麼

直接說

輸入你想要的：「把這個頁面改成深色」「隱藏側邊欄」「幫我摘要」。代理會讀取頁面，並用在頁面中執行的程式碼來修改它。

真正的瀏覽器

分頁與網址列，適用於任何網站。頁面由 WebKit 載入，登入方式和平常一樣。

留住好用的修改

代理可以把修改儲存成該網站的小腳本。每個腳本你都可以檢視、關閉或刪除，也可以匯入自己的使用者腳本。

摘要與朗讀

摘要你正在讀的頁面，讓它念給你聽，或用語音和代理對話。

翻譯

使用 Apple 的裝置端翻譯來翻譯頁面。

自選 AI

使用你自己的 API 金鑰連接代管服務、使用區域網路上的模型，或在支援的裝置上使用 Apple 智慧。

更少的廣告與追蹤器

選用的封鎖功能，過濾規則隨 App 一起提供，並在你的裝置上編譯。

為謹慎而設計

  • 預設情況下，代理在修改內容或把你的登入狀態傳送到其他網站之前會先詢問。執行期間畫面上一直有「停止」按鈕。
  • 除非你在設定中開啟，Cookie 的值不會提供給 AI。
  • 網頁上的文字一律視為不可信，網頁無法對代理下指令。
  • 你的 API 金鑰儲存在 iOS 鑰匙圈中。

代理使用的是你瀏覽時的同一套登入狀態。使用時請避免登入銀行、支付或主要電子郵件帳號。

你的資料

沒有 WukongMind 伺服器，沒有帳號，沒有分析，也沒有追蹤。你向代理提問時，所需的頁面內容會直接從你的裝置傳送給你選擇的 AI 供應商。請閱讀隱私權政策。

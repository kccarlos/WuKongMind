What it does

Just ask

Type what you want: “make this page dark”, “hide the sidebar”, “summarize this”. The Agent reads the page and changes it with code that runs in the page.

A real browser

Tabs and an address bar, on any site. Pages load in WebKit and you sign in the usual way.

Keep what works

The Agent can save a change as a small script for that site. You can read, switch off or delete every script, and import your own user scripts.

Summarize and listen

Summarize the page you are reading, have it read aloud, or talk to the Agent with your voice.

Translate

Translate a page with Apple’s on-device Translation.

Your choice of AI

Use your own API key with a hosted provider, a model on your local network, or Apple Intelligence on devices that have it.

Fewer ads and trackers

Optional blocking with filter lists that are bundled with the app and compiled on your device.

Built to be careful

  • The Agent asks before it changes things or sends your login to another site, by default. A Stop button is always on screen while it works.
  • Cookie values are not given to the AI unless you turn that on in Settings.
  • Text on a web page is treated as untrusted, so a page cannot give the Agent orders.
  • Your API keys stay in the iOS Keychain.

The Agent works inside the same browser sessions you use. Avoid signing in to banking, payment or main email accounts while you use it.

Your data

There are no WukongMind servers, accounts, analytics or tracking. When you ask the Agent something, the page content it needs goes straight from your device to the AI provider you chose. Read the privacy policy.
